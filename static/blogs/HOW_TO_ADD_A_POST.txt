# Blog posts (beginner guide)
# ===========================
#
# Each `.md` file here becomes `/blogs/<filename-without-md>`.
# Do NOT put helper docs as `*.md` in this folder — use `.txt` (like this file)
# so the site does not try to render them as posts.
#
# You can also publish via the Admin portal (navbar → Login) if your
# @uwaterloo.ca email is allowlisted + email-verified.

## Required frontmatter

```yaml
---
title: 'My Post Title'
date: 'March 12 2026'
image: '/imgs/projects/eve/eve-hero.jpg'
description: 'One or two sentences shown on cards and the listing hero.'
tags: ['EVE', 'Perception']
authors: ['WATonomous Autonomy Team']
spotlight: true
ownerEmail: 'alice.chen@uwaterloo.ca'
---
```

| Field | Notes |
|-------|--------|
| `title` | Hero + cards; teal `//` accent in the UI |
| `date` | Prefer `MMMM DD YYYY` |
| `image` | Path under `public/` (file must exist) |
| `description` | Card / search blurb |
| `tags` | Controlled set preferred: EVE, Micro, Rover, Humanoid, Competition, Team News, Perception, Planning, Sponsors |
| `authors` | Always a YAML list |
| `spotlight` | `true` → Spotlight carousel on `/blogs` |
| `ownerEmail` | Optional; set automatically when publishing via Admin (IDOR ownership) |

Reading time ("N min read") is computed automatically from the markdown body.

## After the `---`

Write normal Markdown (headings, lists, links, images).
